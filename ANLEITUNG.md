## Installation auf GitHub Pages

1. Repository öffnen → **Add file → Upload files**
2. **Gesamten Inhalt** dieser ZIP hochladen (alle Dateien im Root)
3. Commit → 1–2 Minuten warten → Seite hart neu laden (oder Home-Screen-App neu öffnen)

Daten (Räume, Lernfortschritt) bleiben erhalten. **Trotzdem vorher Backup machen.**
